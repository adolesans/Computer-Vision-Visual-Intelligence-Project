# Computer Vision & Visual Intelligence

This section highlights my work in enabling machines to "see" and interpret the world. I focus on real-time object detection, tracking, and deploying vision models into production environments.

## Project Index

### 1. Nagrak-Vision: Vehicle Detection & Tracking
> **Real-Time Traffic Analytics**

* **Objective**: To automate traffic counting and classification at the Nagrak Toll Gate.
* **Innovation**: Built a production-ready pipeline using **YOLOv5** for detection and **OpenCV** for object tracking. The system feeds data into a real-time dashboard for congestion analysis.
* **Tech Stack**: YOLOv5, OpenCV, Streamlit, Python.
* **🔗 Repository**: [Link to Nagrak Vision](https://github.com/adolesans/Computer-Vision-Visual-Intelligence-Project/tree/main/Nagrak-Vehicle-Detection-Tracking-and-Counting)

## Core Competencies Demonstrated
* **Object Detection**: Implementing State-of-the-Art (SOTA) models like YOLO.
* **Video Processing**: Handling real-time video streams and inference.
* **Deployment**: Integrating vision models with user interfaces (Streamlit).
